About this project
Faculty-to-faculty OER recommendations

Too many OERs?
Start with the ones faculty recommend.

A casual, independent project for California Community College English faculty to share which open educational resources are actually worth exploring.

The idea is simple.

The ASCCC OERI already maintains an excellent collection of English OER. This project adds one practical layer: What are other CCC English faculty actually using and recommending?

Browse by course, see which texts rise to the top, and eventually add your own recommendation or brief teaching note.

Choose Your Course

Start with the course you teach. Each page will rank available OER based on recommendations from California Community College English faculty.

How It Works

1

Find your course.

Go directly to the OER options associated with the course you teach.

2

See what faculty recommend.

Quickly identify which resources other CCC English faculty think are worth opening first.

3

Share what worked.

If you have used a resource, add a quick recommendation or teaching note to help the next faculty member.

Built beside OERI, not instead of it.

ASCCC OERI maintains the comprehensive, discipline-curated collection of English OER. This independent project is simply a faculty-to-faculty recommendation layer designed to make that collection easier to navigate.
