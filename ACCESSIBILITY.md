# Accessibility

CCC English OER Picks is designed with accessibility as a core requirement. The project aims to meet or exceed **WCAG 2.2 Level AA** for the parts of the experience controlled by this repository.

## First-party accessibility features

The site uses semantic page structure and landmarks, skip links, keyboard-accessible navigation and controls, visible focus indicators, responsive layouts that reflow on smaller screens, labeled form fields, live status messages for dynamic updates, accessible dialog labeling, target-size support for controls, and reduced-motion behavior.

## Testing approach

After publishing significant updates, first-party pages should be checked with the WAVE browser extension and reviewed manually for keyboard access, focus order and visibility, heading structure, form labels and instructions, link purpose, zoom/reflow, accessible names, and color contrast. Automated tools are useful for catching common problems but cannot certify legal compliance or replace human and assistive-technology testing.

## Third-party services

GitHub Pages, Supabase, Google Groups, and external OER platforms are maintained by their own providers. Their accessibility features and barriers are outside the direct control of this repository.

## Report a barrier

Accessibility barriers in the CCC English OER Picks site can be reported to Karen Crozer at karencrozer@gmail.com. Please include the page and a short description of the problem when possible.
