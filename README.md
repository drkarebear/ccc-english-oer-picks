# CCC English OER Picks

CCC English OER Picks is an independent faculty project that helps California Community College English faculty compare promising OER by course using transparent, course-specific rubrics.

## Review method

Each course rubric is developed from statewide Common Course Numbering expectations and related curriculum guidance. AI is used for a structured first pass across large OER, including draft criterion ratings and possible supporting evidence. Karen Crozer then performs a human editorial pass by checking the source material, revising unsupported or overstated ratings, and making the final decision about what is published.

The project is not currently publishing formal IDEA Framework scores, badges, or crosswalks. Relevant representation, inclusion, equity, anti-racism, and accessibility observations may still appear qualitatively when supported by evidence.

## Related project

Broader prompts for finding, comparing, evaluating, and planning with OER and other zero-cost materials now live in [The OER Promptbook](https://drkarebear.github.io/OER-Promptbook/).

## AI ethics

The project's responsible-use approach is informed by the PAIRR statement [“AI Is Problematic. Why Does PAIRR Use It?”](https://juliegamberg.github.io/ai-is-problematic-why-pairr-uses-ai/). Karen Crozer is a co-PI on PAIRR but did not author that statement.
